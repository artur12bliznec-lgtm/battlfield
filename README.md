# Battlfield — модели

![Бойцы обеих сторон, оружие и бинт](docs/lineup.jpg)

Первый этап игры в духе Battlefield: low-poly модели бойцов двух сторон, оружия и бинта.
Модели готовы для игрового движка: у бойцов есть скелет и анимации, у оружия — точки крепления.

## Что внутри

| Модель | Файл в `assets/models/` | Треугольники | Особенности |
|---|---|---:|---|
| Боец Альянса (синие) | `soldier_alliance.glb` | 8 852 | плитник, рация с антенной, наушники, шлем с высоким вырезом |
| Боец Коалиции (красные) | `soldier_coalition.glb` | 8 200 | разгрузка, рюкзак со скаткой, балаклава, очки-маска, шарф |
| Автомат | `assault_rifle.glb` | 3 996 | АК-образный, магазин снимается |
| Винтовка | `rifle.glb` | 4 890 | снайперская, оптический прицел, складные сошки |
| Пулемёт | `machine_gun.glb` | 5 224 | ПКМ-образный, короб с лентой, складные сошки |
| Пистолет | `pistol.glb` | 3 428 | полимерная рамка, магазин снимается |
| Бинт | `bandage.glb` | 2 516 | рулон марли с размотанным концом |

Стороны различаются не только цветом формы, но и силуэтом, чтобы врага можно было узнать издалека.
Цвет команды — на повязках на рукавах и на шевроне на шлеме.

## Анимации бойцов

![Стойка, прицеливание, ходьба, бег, пистолет](docs/animations.jpg)

В файле каждого бойца 10 анимаций: `Idle`, `Walk`, `Run`, `Rifle_Idle`, `Rifle_Aim`, `Rifle_Walk`,
`Rifle_Run`, `Pistol_Idle`, `Pistol_Aim`, `Pistol_Walk`.

Руки в анимациях `Rifle_*` выставлены под автомат, в `Pistol_*` — под пистолет. В просмотрщике
руки подстраиваются под любое оружие через инверсную кинематику (IK). В игре так же обычно
доводят левую руку до цевья.

## Как посмотреть и пересобрать

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
npm install
npm run dev      # просмотрщик моделей: http://localhost:5173
npm run export   # пересобрать assets/models/*.glb
```

В просмотрщике модель можно вращать, выбрать бойцу оружие и анимацию, разложить сошки,
включить точки крепления и каркас, скачать `.glb`.

## Как подключить в движке

Формат — glTF 2.0 (`.glb`). Его открывают:

- **Unity** — через пакет [glTFast](https://docs.unity3d.com/Packages/com.unity.cloud.gltfast@latest), затем `.glb` перетаскивается в `Assets`;
- **Unreal Engine 5** — Import, выбрать `.glb`;
- **Godot 4** — достаточно положить `.glb` в папку проекта;
- **Blender** — File → Import → glTF 2.0 (оттуда можно сохранить в FBX);
- **three.js, Babylon.js** — `GLTFLoader`.

Кости бойца названы как у Mixamo (`Hips`, `Spine`, `LeftArm`, `RightUpLeg`…), поэтому скелет
легко сопоставить с чужими анимациями при ретаргетинге.

### Соглашения

- Единицы — метры. Ось Y — вверх, Z — вперёд (лицо бойца, ствол оружия), X — влево.
- Боец стоит в T-позе, подошвы на `y = 0`, рост около 1,8 м.
- Начало координат оружия — в точке хвата правой рукой.

### Точки крепления оружия

| Узел | Назначение |
|---|---|
| `grip_r` | хват правой рукой; ось +Y узла идёт вдоль рукояти |
| `grip_l` | хват левой рукой: цевьё, сошки или рукоять пистолета |
| `sight` | положение глаза при прицеливании (камера в режиме прицела) |
| `muzzle` | дульный срез: вспышка и вылет пули |
| `stock` | точка упора приклада в плечо |
| `eject` | окно выброса гильз |
| `magazine` | магазин или короб — отдельный узел для анимации перезарядки |
| `bipod_leg_l`, `bipod_leg_r` | ноги сошек у винтовки и пулемёта; поворот по X их раскладывает |

### Гнёзда бойца

- `socket_weapon_r` — в правой кисти. Чтобы вложить оружие в руку, совместите его узел `grip_r` с этим гнездом.
- `socket_weapon_l` — в левой кисти, для подгонки левой руки к `grip_l`.
- `eyes` — точка между глаз, для камеры от первого лица.

Пример на three.js:

```js
const weapon = rifleGltf.scene;
const grip = weapon.getObjectByName('grip_r');
new THREE.Matrix4()
  .compose(grip.position, grip.quaternion, new THREE.Vector3(1, 1, 1))
  .invert()
  .decompose(weapon.position, weapon.quaternion, weapon.scale);
soldierGltf.scene.getObjectByName('socket_weapon_r').add(weapon);
```

## Как устроен проект

```
src/models/
  kit.js              инструменты моделирования: профили, лофты, тела вращения
  materials.js        палитра материалов
  weapons/            автомат, винтовка, пулемёт, пистолет
  items/bandage.js    бинт
  soldier/            скелет, геометрия тела, снаряжение фракций, анимации и IK
  lineup.js           обзорная сцена со всеми моделями
src/viewer/           просмотрщик
scripts/export-glb.mjs  выгрузка всех моделей в .glb с проверкой
assets/models/        готовые .glb
```

Модели строятся кодом из деталей с размерами в метрах, поэтому их легко менять. Цвета формы
и снаряжения сторон — в `src/models/soldier/factions.js`, цвета оружия — в
`src/models/materials.js`. После правок выполните `npm run export`.
